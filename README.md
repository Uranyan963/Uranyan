# たまふら｜多摩地域の休日イベント

東京都の多摩地域26市（23区以外の市）の公式サイトからイベント情報を毎日集めて、休日にふらっと行けるイベントを探せるサイトです。

## できること

- **次の休み / 30日以内 / 90日以内 / 📅日付** の切り替え（土日・祝日に対応。日付はカレンダーで1日または期間を選択、各日の件数つき）
- **リスト / 地図** の切り替え（地図は国土地理院の地図タイル。ピンを押すと詳細）
- **大きなイベント**（まつり・花火・フェスなど）を色分けし、「大きなイベントだけ」で絞り込み
- **どこから**：現在地、登録した場所（自宅・最寄り駅など）、各市の市役所を選ぶと、そこからの**距離で絞り込み**
- **よく使う場所を登録**：住所検索（国土地理院）か現在地で登録。この端末のブラウザにだけ保存
- カテゴリ・**市で絞り込み**（複数選択）
- 各イベントから「行き方（Googleマップ）」「公式ページ」「Googleカレンダーに追加」（期間のあるイベントは行く日を選んでその日だけ追加）
- 見つけたイベントを自分で追加（この端末のブラウザにだけ保存）
- スマホのホーム画面に追加して使える（Web App Manifest）

## 仕組み

```
GitHub Actions（毎朝5:37）
  ├ npm test
  ├ 公開中の data/events.json を取得（失敗した市の引き継ぎ用）
  ├ scraper/collect.mjs で26市のサイトを読む → data/events.json
  └ GitHub Pages に公開（index.html, src/, data/）
ブラウザ
  └ 静的ページが data/events.json と登録イベント（src/data.js）を読み込んで表示
```

サーバーもデータベースもない静的サイトなので、GitHub Pages で無料で公開できます。データはリポジトリにコミットせず、公開のたびに作り直します。

### 公開の手順（初回のみ）

1. このブランチを `main` にマージする
2. リポジトリの **Settings → General** で Default branch を `main` にする（毎朝の自動実行はデフォルトブランチで動く）
3. **Settings → Pages** の Source を **GitHub Actions** にする
4. **Actions → deploy (収集して公開) → Run workflow** で初回の公開を実行する
5. `https://uranyan963.github.io/tamafura/` で公開される（URLはリポジトリ名で決まる。Settings → General の Repository name で変えられる）

### 運用

- 毎朝自動で取得・公開します。5市以上で取得に失敗するとワークフローが失敗し、GitHub からメールが届きます（公開中のサイトは前回のまま）。
- 公開リポジトリでは、60日間リポジトリに動きがないと GitHub が定期実行を止めることがあります。止まったら Actions タブから再開してください。
- 掲載の誤り・掲載停止の依頼は GitHub Issues で受け付けます（サイトの「このサイトについて」にリンクあり）。

## 市の公式イベントの取得

市ごとの取得方法は `scraper/sources.mjs` にまとめています。手元で1市だけ試すなら `node scraper/collect.mjs 三鷹市`、全部なら `npm run collect`。

| 読み取り方 | 市 | コード |
| --- | --- | --- |
| イベントカレンダーのデータファイル（JSだが実行せずJSONとして解析） | 日野・国分寺・立川・武蔵野・昭島・東大和・清瀬・東久留米・多摩・稲城 | `scraper/parsers/futureinn.mjs` |
| 日付の表・見出しの下にリンクが並ぶカレンダー（今月から3か月分） | 府中・町田・小金井・西東京・調布・あきる野・八王子・青梅・狛江 | `scraper/parsers/daytable.mjs` |
| JSON | 国立 | `scraper/parsers/kunitachi.mjs` |
| 一覧ページ（ページ送り） | 三鷹 | `scraper/parsers/mitaka.mjs` |
| 未対応 | 小平（サイトが臨時案内ページ）・東村山（自動取得のアクセスを拒否）・羽村（イベントカレンダーに掲載なし）・福生・武蔵村山（robots.txt で自動取得を禁止） | |

相手のサイトに迷惑をかけないように、`scraper/fetch.mjs` で次のことをしています。

- robots.txt で禁止されているURLは取得しない
- 同じサイトへは1.5秒以上あけて1件ずつ取得する
- User-Agent に連絡先（このリポジトリ）を入れる

掲載するのはタイトル・日付・場所・元ページへのリンクだけで、説明文は転載しません。

- 相談会・説明会・講座・定例サークル・子育てひろば・健診など「ふらっと行く」向きでないもの、60日を超えて続くもの、半年より先のものは `scraper/normalize.mjs` で除外しています。
- 自動取得したイベントの位置は、会場名を国土地理院の住所検索で調べています（`scraper/geocode.mjs`、結果は `data/geocache.json` に保存して再利用）。分からないものは市役所の位置（`src/data.js` の `CITIES`）です。
- 「大きなイベント」はタイトルなどから自動判定しています（`scraper/normalize.mjs` の `BIG`）。
- 新しいサイトを足すときは `scraper/probe-urls.txt` にURLを書いてpush（または Actions の「probe」を手動実行）すると、ページが `scraper/probe/` に保存されるので、中身を見て読み取り部分を書きます。

## 登録イベント（例年の行事）

`src/data.js` の `EVENTS` に「例年こういう日程」というルールで登録し、日付を自動で計算しています。

| ルール | 例 |
| --- | --- |
| `fixed` 毎年同じ日付 | くらやみ祭 4/30〜5/6 |
| `nthWeekday` 第n◯曜日 | 新選組まつり（5月第2土日）、ジャパンカップ（11月最終日曜） |
| `monthly` 毎月第n◯曜日 | 高幡不動 ござれ市（第3日曜） |
| `tori` 11月の酉の日 | 大國魂神社 酉の市 |

祝日は `src/dates.js` の `HOLIDAYS`（現在 2026〜2027年）。年が変わる前に追記が必要です。
