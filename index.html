      多摩地域26市の公式サイトと取得状況
        このサイトについて・ご利用にあたって

        たまふらは、東京都の多摩地域26市の公式サイトに載っているイベント情報を毎日自動で集めて、休日に気軽に行けるイベントを探しやすくした個人運営のサイトです。各市が運営しているものではありません。

        • 掲載しているのはイベントのタイトル・日付・場所と、元のページへのリンクです。内容・申込方法・中止や変更は、必ずリンク先の公式ページで確認してください。
        • 相談会・説明会・講座・定例の教室・子育てひろば・健診など、「ふらっと行く」向きでないものは自動で除いています。そのため、各市のすべてのイベントが載っているわけではありません。
        • 目安 の付いたイベントは「例年このころ」という日程から計算したもので、年によってずれることがあります。
        • 市の公式情報の距離は、市役所の位置からの目安です。
        • 掲載内容の正確さは保証できません。このサイトの利用によって生じた損害について、運営者は責任を負いません。

        プライバシー

        • 登録した場所・自分で追加したイベント・表示の設定は、この端末のブラウザにだけ保存されます。運営者には送られません。
        • 「現在地」は距離の計算にだけ使い、保存も送信もしません（「今いる場所を登録する」を押したときだけ、この端末に保存します）。
        • 住所検索で入力した文字は、検索のため国土地理院に送られます。
        • アクセス解析や広告は使っていません。

        掲載内容の誤りや、掲載を止めてほしいなどのご連絡は GitHub の Issues へお願いします。
